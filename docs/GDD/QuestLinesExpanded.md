## Daily and Weekly Quests

### Daily Quests

**Types**
- **Hunting:** Kill creatures
- **Crafting:** Create items
- **Gathering:** Collect resources
- **Trading:** Buy/sell items
- **PvP:** Win battles

**Rewards**
- Gold
- Reputation
- Resources
- Tokens

### Weekly Quests

**Types**
- **Raids:** Complete raid
- **Dungeons:** Run dungeons
- **PvP:** Win ranked
- **Events:** Participate
- **Challenges:** Complete hard

**Rewards**
- Epic gear
- Rare materials
- Mounts
- Titles
